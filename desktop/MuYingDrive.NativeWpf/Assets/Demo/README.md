# Native WPF demo thumbnails

These locally generated samples exercise asynchronous thumbnail loading, justified row geometry, selection, and scrolling in the demo UI. They show a mountain lake, minimalist architecture, a cinema camera, a greenhouse, and an empty theater stage. `sample-06.mp4` is a short local preview clip generated from the camera image to exercise Windows Shell video thumbnails.

They are demonstration assets, not NAS content or real employee files. The application labels the workspace and seeded entries as demo data.
