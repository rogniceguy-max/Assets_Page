# WPF 工作簿与项目空间控件

这是可由主程序引用的 WPF 类库，不含 App 入口。`ProjectSpaceShell.xaml` 提供新的左侧导航和项目媒体壳层；`ProjectWorkbooksView.xaml` 是可嵌入的工作簿内容页，保留节拍、评论评价、图片选择和拖放交互。

## 当前界面约定

- 全局主导航是`图片`、`视频`、`个人空间`、`传输`、`反馈`；另设`项目 +`导航分组。
- 全局图片和视频页浏览所有项目，并按项目分组；项目树中的媒体入口按该项目或文件夹筛选。
- 新建项目由宿主一次创建项目及默认的`节拍表`、`资产表`，确认后才显示在导航中。项目全员可读写；个人空间仅本人可见可读写。
- 资产表创建资产行时，后端应同时创建对应图片文件夹。拖入备选会进入该文件夹；软删除进入项目回收站并保留原图、评论和评价。
- `11 · 节拍工作表`内部组织仍未定，本次不改其内容模型。

## 合并前需要宿主接线

项目/文件夹快照、项目创建与改名、图片/视频查询和上传、资产行与文件夹创建、媒体软删除与恢复、个人空间私有权限都由主程序服务提供。壳层通过事件发起请求，并只在收到后端确认结果后更新状态；未接入时会明确显示服务尚未接入，不会本地伪造成功。

逐项事件、服务模型和暂缺接口见 [INTEGRATION.md](INTEGRATION.md)。方向记录见 [DESIGN_DIRECTION_DRAFT.md](../DESIGN_DIRECTION_DRAFT.md)。
