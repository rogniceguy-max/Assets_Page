## 已确认需求

- 登录页提供免登录参观入口，无需参观者填写用户名或密码。
- 参观者可见影视资源库、文学资源库和公共区，全部只读。
- 员工个人空间仍隔离；参观响应不返回个人空间路径，直接猜测路径也必须被服务及 ACL 拒绝。
- 禁止上传、创建、覆盖、重命名、移动、删除和权限修改。读取包括列举、预览和下载；下载作为读取处理，不赋予 NAS 写权限。
- 员工现有权限原则不变：本部门读写、另一部门只读、公共区读写、个人空间相互隔离。
- 本阶段只在批准的独立测试环境验证，不修改生产目录及现有文件，不批量递归覆盖 ACL。

## 推荐方案：HTTPS 低权限只读通道

参观客户端通过 HTTPS 请求参观会话，使用专用的只读文件通道完成列表、预览、下载。服务器文件读取进程使用独立 UGOS 原生参观身份，真实受 UGOS ACL 约束；不以 root 或管理员读取后仅靠应用代码筛选文件。

客户端不保存或接收 NAS 管理员密码，也不内置共享 SMB 密码。参观通道不建立第二个 Windows SMB 身份，避免与资源管理器或员工现有 NAS 连接产生身份冲突。员工 SMB 文件通道继续保留，两个通道通过文件目录/读取接口解耦。

候选接口职责（名称尚未定稿，均待实施）：

1. 创建可撤销的参观会话，返回角色 `visitor`、三个允许空间及只读能力，不返回个人路径或员工会话。
2. 按服务端空间 ID 列举目录，返回相对文件标识；拒绝客户端提交任意服务器绝对路径。
3. 提供文件读取、预览及支持 Range 的下载；限制符号链接、路径穿越及解析/打开之间的竞态，不允许逃逸到授权目录之外。
4. 所有写接口在服务端拒绝 visitor；低权限进程的实际 ACL 作为第二层约束。隐藏按钮不构成权限控制。
5. 退出参观只撤销参观会话，不清除员工保存的凭据，不取消其他 Windows 程序的 SMB 连接。
6. 参观下载缓存及断点使用独立命名空间，不复用员工账号 ID 或其未完成传输。文件变化时正确拒绝失效断点。

实际监听范围、网络准入、参观会话期限和并发/下载资源限制需在部署前确定；不能把免登录入口自动解释为允许公网开放。不能为实现参观而启用 Windows 不安全 guest 登录或关闭 SMB 安全策略。
